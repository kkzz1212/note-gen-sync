# How to Efficiently Use NoteGen for Note Management

This is my first record in NoteGen.

I can first quickly jot down scattered ideas without organizing the structure at the beginning.

Later, I can organize these records into a formal note and continue editing.

If I feel the content is not smooth enough, I can use AI to polish, rewrite, or supplement the key points.

After finishing, the note will be saved in a local Markdown file, making it convenient for future searching and management.
